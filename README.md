# 数独时光 · 微信小程序

原生微信小程序，无第三方依赖、无需后端。支持三档难度、唯一解随机题目、计时、笔记、实时错误标记、撤销、擦除、提示和本地进度恢复。

## 运行

1. 安装微信开发者工具，导入本仓库目录，项目类型选择小程序。
2. 当前使用 `touristappid` 进行本地体验；真机调试、预览和发布时，在开发者工具中填写你自己的小程序 AppID。
3. 点击编译，首页即为游戏。无需 npm 安装或服务启动。

## 验证

运行 `node --test tests/*.test.js` 验证数独生成算法。微信界面及设备兼容性需在微信开发者工具和真机验证。

难度以挖空数量区分，不代表严格的人类解题技巧分级。提示不限制次数，错误计数为累计错误输入次数，撤销不回退计时和错误次数。游戏进度保存在当前设备本地，不包含云端同步。
